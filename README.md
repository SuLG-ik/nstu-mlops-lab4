# Лабораторная работа 4. MLOps

**Вариант 14: прогноз прочности бетона на сжатие.**

Ненашкин В. Д., АВТ-313, НГТУ. Дисциплина «Системы искусственного интеллекта и машинное обучение», преподаватель Антонянц Е. Н.

Работа выполнена в [lab4.ipynb](lab4.ipynb): данные, обучение, сравнение экспериментов в MLflow, версии модели, API в Docker, обновление, откат и дополнительные задания. Пояснения и результаты находятся рядом с кодом в ноутбуке.

## Данные

[Concrete Compressive Strength — UCI](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength), I-Cheng Yeh, 1998. Лицензия данных — [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

`concrete.csv` содержит 1030 наблюдений. Семь компонентов смеси измерены в кг/м³, возраст — в днях, целевая прочность — в МПа. Исходный XLS преобразован в CSV: заменены заголовки, порядок и значения строк сохранены. Рецептуры разделены между train, validation и test без пересечений.

SHA-256 CSV: `3ab599b33547715db9c672788f3d3316b730fbca689a469afe2488f03b4a7a05`.

## Запуск

Нужны Python 3.12 и запущенный Docker с Compose. Порты 5001, 5002 и 8000 должны быть свободны. Из папки репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook lab4.ipynb
```

В ноутбуке выбрать ядро созданного окружения и выполнять ячейки по порядку. Он сам запускает MLflow и создаёт базу в `runtime/notebook-mlflow/`.

Адрес MLflow во время работы — `http://127.0.0.1:5001`; API после запуска — `http://127.0.0.1:8000/docs`.

Все команды Docker и проверки приведены в ноутбуке. Модель, база MLflow, журналы и промежуточные файлы создаются локально и не входят в Git.
